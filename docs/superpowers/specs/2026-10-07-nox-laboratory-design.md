# NOX Laboratory — implementation brief

The user's October 7 brief authorizes a complete frontend revamp and practical improvements to NOX's capabilities, preserving routes, integrations, expressions, recording, voice, history and the smooth legless blob. Free tiers only. NOX is a fictional character, not sentient or a superintelligence.

## Experience

Ivory paper, charcoal ink and restrained deep teal form the shared editorial system. The character's dark stage remains a deliberate visual anchor. Large confident headings, readable controls, consistent borders and space replace the old tiny, low-contrast interface. `/`, `/app`, and all existing workspace hashes remain valid. Existing empty, error, locked and loading states remain truthful.

The homepage has a real Three.js sculpture of offset translucent panels around NOX, representing layers of context. Static fallback works without WebGL. Stage/Face remains responsible for NOX, including scrolling peek. React islands add useful interface features without replacing engine-owned DOM. GSAP owns hero/reveal/scroll wrapper transforms; Lenis owns desktop homepage document scroll; React Spring owns sculpture rotation; Motion owns React menu, dialog and notebook transitions; Three owns rendering. Reduced motion disables decorative animation; mobile retains native touch scroll.

## Useful intelligence

Quick, balanced and deep answer modes trade latency/quota for detail. A browser-local knowledge notebook imports text/Markdown and retrieves bounded relevant excerpts; the UI shows what will accompany a question. Excerpts are untrusted reference data, never privileged instructions. No autonomous browsing, arbitrary commands, paid services or hidden tool execution. Existing summaries, provider selection, speech cache and measured timing remain.

## Security and storage

Keep secrets server-side, owner-cookie authentication, same-origin requests, validated structured packets, bounded requests and allowlisted actions. Add bounded failed-unlock throttling and enforce explicit remember intent in code. Local notes/history are readable browser storage, not encrypted cloud accounts. In-memory serverless rate limits are defense in depth, not global abuse protection. No claim of security certification or unlimited free inference.

## Acceptance

All existing routes, character gestures, media controls, forms and integrations preserved. Knowledge retrieval/depth/security behavior has meaningful tests. Desktop/tablet/mobile layouts and keyboard/dialog behavior are checked. Build bundles requested libraries locally under a self-only script CSP. Full verification, dependency audit, independent review and browser QA precede publication. Founder documentation explains modules, data flow, threat model, algorithms, tradeoffs, free-tier limits and measured results.
