# NOX Signal Core Implementation Plan

> Execute inline with the executing-plans workflow. The user explicitly requested implementation and visual exploration; no additional design approval round is needed.

**Goal:** Replace the literal face and generic dashboard with a custom, expressive orb inside a tactile analog console.

**Architecture:** A small pure state module drives an original WebGL fragment shader. An offscreen GPU canvas is composited into the existing 2D stage, preserving camera, captions, scene actions, and recording. A Canvas fallback keeps NOX usable without WebGL. HTML and CSS provide the physical console around it.

**Tech stack:** Existing native JavaScript, WebGL 1 / GLSL, Canvas 2D, CSS. Reference research: ThreeUI orb gallery, ShaderGradient repository, Motion animate documentation, GSAP easing documentation. Visual inspiration only; no copied premium source or framework migration.
