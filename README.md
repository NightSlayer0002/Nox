# NOX / Laboratory

A curious mind, a little company. An expressive AI companion with a live blob, a source-based fluid homepage, a knowledge notebook, adjustable answer depth, and a creation studio. React interface islands coexist with the original Canvas/WebGL character engine and Node 24 server. All libraries are pinned and bundled locally.

Live website: [nox-iota-lemon.vercel.app](https://nox-iota-lemon.vercel.app/). Source: [NightSlayer0002/Nox](https://github.com/NightSlayer0002/Nox). Pushing `main` automatically starts a Vercel production deployment.

Try the [temporary guest visit](https://nox-iota-lemon.vercel.app/guest#conversation).
Guest chats, notes and receptions stay in memory and disappear on refresh. Your
visit never loads the owner's local archive. The bounded trial uses Groq's quick
model and public male Orpheus voice. [Owner workspace](https://nox-iota-lemon.vercel.app/owner#conversation)
uses the private NOX owner token to open this browser's saved archive and full
studio. There is no shared chat database or cross-device account sync.

## Start locally

```powershell
npm.cmd ci --ignore-scripts
npm.cmd start
```

Open http://127.0.0.1:3000 for the landing page, then enter the workspace at `/app`. Dark is the default; a deliberate new Light choice can be saved. NOX follows your cursor across the browser window. Click him, drag him, or double-click to wink. Presence is the soft blob; Liquid Metal applies liquid-logo’s flowing Chrome shader to that same character. Signal is a faceless liquid core. NOX motion stays on with no website switch, including when the browser requests reduced motion as explicitly requested by the owner. ShaderGradient’s Mint water-plane scene animates automatically; GPU drawing is capped at 30 FPS and stops when the page is hidden. Voice starts on and preserves a saved off choice; browser audio still needs interaction. Scene programs stop on a second click. F enters portrait film mode; Escape resets the scene.

## Give him a brain

Copy `.env.example` to `.env`, add a free-plan `GROQ_API_KEY`, and restart. `NOX_PROVIDER=groq` uses GroqCloud first. Optional `GEMINI_API_KEY` and `NVIDIA_API_KEY` add manual switches in Settings. Keys stay server-side. Without a key the clearly labeled offline demo remains scripted; with a configured provider replies are generated by its language model.

`NOX_NATURAL_VOICE=1` enables public Groq Orpheus speech, defaulting to Troy. Speech uses a separate provider quota; Browser voice is a fallback. Owner mode requires a private `NOX_ACCESS_TOKEN` and creates a protected cookie session for up to 12 hours. Guest chat and voice need no owner token. Guest replies use the fixed quick Groq model; owner notebook context, summaries and new AFTERIMAGE writing remain protected. Public chat and voice each allow four calls per client and twelve total per minute per warm process. These maps are bounded and process-local, not distributed budgets; provider free quotas still apply. Do not put real secrets in Git or chat.

Free tiers are limited, not unlimited. Stay on a provider's free plan without paid billing for a free-only setup. NVIDIA hosted access is a trial; Gemini free-tier content may be used to improve Google's products. Vercel Hobby is personal/non-commercial. See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) for official references and every setup step.

## Create with him

Companion, Director, and Uncanny change his persona. Gravity, Spotlight, Orbit, Echo, and Takeover are bounded authored programs the model can also request. A reply packet can choose speech, mood, scene action, and a short explicitly requested memory. It cannot execute arbitrary code.

Camera preview is local and optional; the model receives text, not camera frames. Owner notebooks stay in this browser; guest scratchpads are temporary. Recording exports a captioned WebM with enabled Orpheus audio, capped at 60 seconds. Browser/OS speech and microphone audio are not captured.

Explore, Conversation, Scene studio, and Library are distinct workspace views. Owner conversations persist locally, with search, reopen, export, and delete; guests get the same controls for their temporary visit. The owner archive holds up to 40 threads with 200 messages each. Export important conversations before clearing browser data or changing domains. Full transcripts stay local while cloud context is bounded. Owner conversations can produce a background model summary; failure never deletes the archive.

Quick, Balanced and Deep retain up to 420, 2,400 and 6,000 written characters. Groq Deep uses GPT-OSS 120B with more reasoning; normal conversation uses the configured model. Voice reads a concise opening independently. Add text/Markdown to Knowledge for local ranked retrieval; inspect relevant source titles before sending. Notes are plaintext browser storage, with no cloud sync.

NVIDIA/Gemini can stream text before the validated mood/action packet. Strict Groq output arrives as a complete packet. Stable prompt prefixes support Groq's automatic prompt caching; a bounded cache reuses identical speech in a warm instance, and hashed frontend chunks can be cached immutably. Neither mechanism guarantees a speed or unlimited quota. NVIDIA defaults to `nvidia/nemotron-3-nano-30b-a3b` with thinking disabled and stays unavailable until a key is configured. Its hosted trial terms require your own review before production use.

Vercel runs `npm run verify` before publishing, so a failed test or syntax check stops that deployment. The build emits `.vercel/output` using Vercel's Build Output API. The output and local secrets are ignored by Git. Once the repository is imported, pushing a validated commit to the production branch triggers Vercel's deployment. Saving a local file alone does not update the public site.
