# NOX / Laboratory

A curious mind, a little company. An expressive AI companion with a live blob, a source-based fluid homepage, a knowledge notebook, adjustable answer depth, and a creation studio. React interface islands coexist with the original Canvas/WebGL character engine and Node 24 server. All libraries are pinned and bundled locally.

Live website: [nox-iota-lemon.vercel.app](https://nox-iota-lemon.vercel.app/). Source: [NightSlayer0002/Nox](https://github.com/NightSlayer0002/Nox). Pushing `main` automatically starts a Vercel production deployment.

Try the [temporary guest visit](https://nox-iota-lemon.vercel.app/guest#conversation).
Guest chats, notes and receptions stay in memory and disappear on refresh. Your
visit never loads the owner’s local archive. Guest chats, activities, notes and
approved preferences clear on refresh. There is no public login or cloud saving.
Conversation and story exports remain available as files.

## Start locally

```powershell
npm.cmd ci --ignore-scripts
npm.cmd start
```

Open http://127.0.0.1:3000 for the landing page, then enter the workspace at `/app`. Dark is the default; a deliberate new Light choice can be saved. NOX looks toward your cursor across the browser window. Click him, drag him, or double-click to wink. Presence is the soft blob; Liquid Metal applies liquid-logo’s flowing Chrome shader to that same character. Signal is a faceless liquid core. NOX motion stays on with no website switch, including when the browser requests reduced motion as explicitly requested by the owner. ShaderGradient’s Mint water-plane scene animates automatically; GPU drawing is capped at 30 FPS and stops when the page is hidden. Voice starts off; enable it when you want spoken replies. Browser audio still needs interaction. Scene programs stop on a second click. F enters portrait film mode; Escape resets the scene.

Normal NOX uses a soft matte 3D body with warm eyes, a mint rim, held stretch and
release wobble. Liquid Metal shares that body and loads its Chrome surface only
when selected. The 635 KB model loads on demand; download or WebGL failures keep
the procedural/Canvas fallback usable. Expressions, narration and captioned
recording share the existing Stage clock, including offscreen recording. See the
[body source and export instructions](assets-source/nox/README.md) to edit or
re-export the asset.

## Give him a brain

Copy `.env.example` to `.env`, add a free-plan `GROQ_API_KEY`, and restart. `NOX_PROVIDER=groq` uses GroqCloud first, with `openai/gpt-oss-120b` as its default model. Optional `GEMINI_API_KEY` and `NVIDIA_API_KEY` add manual switches in Settings. Keys stay server-side. Without a key the clearly labeled offline demo remains scripted; with a configured provider replies are generated by its language model.

`NOX_NATURAL_VOICE=1` enables public Groq Orpheus speech, defaulting to Troy. Speech uses a separate provider quota; Browser voice is an alternative. Owner mode requires a private `NOX_ACCESS_TOKEN` and creates a protected cookie session for up to 12 hours. Guest chat and voice need no owner token. Guest replies use GPT-OSS 120B, with one GPT-OSS 20B fallback only for quota or model-access failures before any answer text is emitted. Other failures are not retried. Reply metrics report the model used and any fallback reason. Both models remain subject to provider free-plan limits; this policy adds no paid service or allowance. Selected temporary notebook excerpts can accompany guest requests. Summaries, deeper developer answers and new AFTERIMAGE writing remain owner-protected. Do not put real secrets in Git or chat.

### Public allowances

Set `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN` on the server to enable
atomic daily counters shared across server instances. The defaults are
`NOX_FREE_TEXT_DAILY=20` accepted chat requests and `NOX_FREE_SPEECH_DAILY=30`
accepted natural-voice requests, with independent budgets. They reset at midnight
**UTC**, and the interface shows the reset time. A voice request is not a voice
minute; accepting a request consumes allowance even if its provider later fails.

These anonymous allowances are shared by a **public IP/network**, not a person
or account. People on the same school, household, mobile or VPN connection can
share a counter. Redis keys use a keyed hash of the network identifier; they do
not contain chat text. Store the REST credentials only in server environment
variables, never in the frontend or Git.

When both Upstash settings are blank, NOX offers a **rate-limited preview** and
does not advertise a durable daily balance. When either setting is supplied but
configuration is incomplete or the store is unavailable, public generation
fails closed until the allowance can be checked. Do not remove those credentials
to work around an outage on an advertised daily-allowance deployment.

Burst protections remain separate: per warm process, chat allows eight calls
per network and twenty-four total per minute; natural voice allows four per
network and twelve total per minute. Process-local throttles are not distributed
spending caps. Provider free quotas and hosting limits still apply. Local
authored Moon exploration, the guessing game and editing existing stories do
not require a new AI generation request. Cloud voice or text requested from
those activities uses its corresponding allowance.

Free tiers are limited, not unlimited. Stay on a provider's free plan without paid billing for a free-only setup. NVIDIA hosted access is a trial; Gemini free-tier content may be used to improve Google's products. Vercel Hobby is personal/non-commercial. See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) for official references and every setup step.

## Create with him

Companion, Director, and Uncanny change his persona. Gravity, Spotlight, Orbit, Echo, and Takeover are bounded authored programs the model can also request. Chat can also stop the active effect. A reply packet can choose speech, mood, scene action, and a short explicitly requested memory. It cannot execute arbitrary code. A bounded interface observation supplies the current route, form, presence, effect, held/grounded state and latest execution receipt to the model. Repeated model requests for the same active effect do not restart it; manual scene buttons keep their toggle behavior. Questions, corrections, quotations and refusals are not fresh action requests.

In Conversation, NOX is a transparent overlay across the chat. His viewport-bounded canvas is 208px on desktop or 144px on phones, with approximately 155px or 107px of visible artwork. He starts beside the welcome within the centered chat width; Park explicitly returns him above the composer. Drag and release to leave him in place; there is no wandering or lateral fling. His controls bot follows his visible right shoulder with a damped spring and brief fading trail; it lifts above that shoulder at the right edge instead of flipping left. Its artwork is 44 × 33px on desktop or 36 × 27px on phones, with a 44px tap target, and opens appearance, expression, Gravity, Takeover, Park and Hide. Gravity falls vertically, with a small landing rebound and one small hop when the mobile keyboard opens while perched; typing alone never parks him. Movement and trail effects share the Stage's effective motion setting; this workspace explicitly keeps motion enabled. Sleep marks fit the floating canvas.

Hold NOX still over a completed message for Explain, Read aloud or Quiz me, or use the message's brain icon by keyboard. A dwell indicator and message highlight show the target; the menu includes an excerpt, action descriptions and keyboard navigation. Message action buttons remain reachable when approached from below. These actions require an explicit choice and protect unsent drafts and edits. Long messages offer Read opening, using the existing bounded voice preview. Call, Scene studio, Afterimage and recording retain their existing stage. Placement lasts for the current page visit.

Camera preview is local and optional; the model receives text, not camera frames. Owner notebooks stay in this browser; guest scratchpads are temporary. Recording exports a captioned WebM with enabled Orpheus audio, capped at 60 seconds. Browser/OS speech and microphone audio are not captured.

With voice enabled, synthesis starts after the reply is validated and the complete answer is saved before presentation waits for actual playback. Preparing voice offers **Show text now**, and text appears after at most four additional seconds even if audio is slow. Unavailable or failed audio releases it immediately. Voice-off replies appear as they stream. Speech reads at most a 420-character opening; ordinary Groq speech rebalances its existing clips for an earlier first clip without adding provider requests. Four-cue Afterimage speech keeps its existing plan. The developer inspector reports preparation and actual playback-start timing. Replaying voice does not repeat a scene action.

The phone button opens a focused voice conversation with the same NOX stage and chat. Opening the view does not request microphone access: Connect starts browser speech recognition. Listening pauses during each reply and resumes after actual playback ends. Mute, Speak now and End cancel pending work; closing or hiding the page stops the microphone. Audio failure preserves the completed written reply. Changing voice settings during preparation releases the text and pauses the call for reconnection. This is a turn-based browser speech interface, not full-duplex audio. Recognition support and processing depend on the browser; ordinary text and voice allowances still apply.

Talk, Explore and Play are connected activities. Explore offers an authored Moon model, clue-first or explanation-first learning, a teach-back and a recap; a different topic or passage opens a real conversation. Play includes an authored guessing game and the Afterimage mystery. Scene studio remains available for character effects and local capture. These controls do not generate arbitrary interactive simulations or AI video.

Owner conversations persist locally, with search, reopen, export, and delete; guests have the same transcript controls for their temporary visit. New archives accept up to 40 conversations with 200 messages each. NOX warns near capacity and refuses additional work at the limit instead of evicting older material; existing larger archives load without pruning. Export a copy and explicitly remove a conversation to make room, or start a new conversation when a thread is full. Guests, including installed guest sessions, clear on refresh; approved guest preferences and activities are also temporary. Full transcripts stay local while cloud context is bounded. Background summaries never delete the archived transcript. On browsers without Web Locks, use one workspace tab when changing saved material or preferences. Unreadable or newer-version archives are left untouched and have an original recovery download. Replacing a protected archive requires an explicit confirmation and keeps the chats composed during the temporary visit. A storage failure switches to temporary work with a visible export reminder.

Quick, Balanced and Deep target 420, 2,400 and 6,000 written characters; complete validated replies have a separate 12,000-character safety ceiling. Input supports up to 6,000 characters. NOX Free offers Quick and Balanced; Deep remains a developer control. Groq Deep uses GPT-OSS 120B with more reasoning; normal conversation uses the configured model. Voice reads a concise opening independently. Add text/Markdown to Knowledge for local ranked retrieval; inspect relevant source titles before sending. Owner notes are plaintext browser storage, while guest scratchpads are temporary, with no cloud sync.

NVIDIA/Gemini can stream text before the validated mood/action packet. Strict Groq output arrives as a complete packet. Stable prompt prefixes support Groq's automatic prompt caching; a bounded cache reuses identical speech in a warm instance, and hashed frontend chunks can be cached immutably. Neither mechanism guarantees a speed or unlimited quota. NVIDIA defaults to `nvidia/nemotron-3-nano-30b-a3b` with thinking disabled and stays unavailable until a key is configured. Its hosted trial terms require your own review before production use.
